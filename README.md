## ✨ Features

- **🔍 Live Search:** Instant real-time search for TV shows and movies.
- **🎭 Genre Filtering:** Filter content easily by genres like Action, Drama, Comedy, Sci-Fi, and more.
- **↕️ Smart Sorting:** Sort shows by highest rating, lowest rating, or title.
- **❤️ Favorites System:** Bookmark favorite shows with data persistent in `localStorage`.
- **🍿 Detailed View Modal:** Click any show card to view full summaries, official site links, languages, and genres.
- **📱 Fully Responsive:** Optimized UI for seamless browsing across mobile, tablet, and desktop displays.

## 🛠️ Tech Stack

- **Frontend:** [React.js](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** CSS3 (Flexbox & CSS Grid)
- **API Integration:** [TVMaze REST API](https://www.tvmaze.com/api)
- **Deployment:** [Vercel](https://vercel.com/)
